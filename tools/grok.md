# Grok

**Shape:** model family with coding surfaces
**Made by:** xAI

## What it is

Not a single agent so much as a model family you can point coding tools at — through xAI's
own surfaces or through third-party clients and editors that let you choose a provider.

It belongs in this comparison for a reason that has nothing to do with capability
rankings: **availability and cost**. If a frontier tool is out of budget, or not offered
where you live, a cheaper or more reachable alternative is not a compromise. It is the
difference between learning this skill and not learning it.

## The workflow it pushes you toward

Whatever workflow the client you use imposes — which is itself the interesting part.
Because the model is separable from the tool, you end up thinking about the two as
different choices: the seat you sit in, and the engine behind it. That is a more accurate
mental model than "which agent is best", and it survives every vendor's next launch.

## What transfers when you leave

Everything, because nothing here is proprietary to the workflow. You still give context,
still ask for a plan, still read the diff, still iterate.

What you also learn — and this transfers to every model you ever use — is how to measure
correction cost. Run the same real task on two engines and count how many times you had to
push back. That number is more useful than any benchmark, because it is measured on your
code, by you.

## What will annoy you

The experience depends heavily on which client you drive it from, so advice you find
online may be describing something that shares only a name with what you installed.

Availability and terms differ by region and move around; check before you build a habit on
top of them.
